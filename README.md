# 🛒 FreshMarket — Интернет-магазин свежих продуктов

Модернизированная версия учебного проекта в рамках учебной практики УП.04.


## 📋 Описание проекта

FreshMarket — это сервис быстрой доставки свежих продуктов с функциями:
- 📦 Каталог товаров с поиском и фильтрацией
- 🛒 Корзина покупок
- 👤 Авторизация пользователей (Покупатель/Администратор)
- 🔐 Админ-панель для управления товарами и заказами
- 💾 Реляционная база данных (SQLite)

## ⚙️ Установка и запуск

### Требования
- Node.js v18+ 
- npm v9+

### Инструкция
```bash
# 1. Клонировать репозиторий
git clone https://github.com/RostislavKozyayev/freshmarket-modernized

# 2. Перейти в папку проекта
cd freshmarket-modernized

# 3. Установить зависимости
npm install

# 4. Инициализировать базу данных
node seed.js

# 5. Запустить сервер
node server.js

# 6. Открыть в браузере
http://localhost:3000
```

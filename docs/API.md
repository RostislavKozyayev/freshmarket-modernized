# Документация API проекта FreshMarket


## Базовый URL
http://localhost:3000/api


## Товары (Products)

### Получить все товары

| Параметр |       Значение      |
|----------|---------------------|
| Метод    | GET                 |
| URL      | /products           |
| Ответ    | JSON массив товаров |

**Пример ответа:**
```json
[
  {
    "id": 1,
    "name": "Яблоки Голден",
    "price": 199,
    "emoji": "🍎",
    "category": "fruits",
    "weight": "1 кг",
    "stock": 50
  }
]
```

### Добавить товар

|  Параметр  |  Значение  |
|------------|------------|
| Метод      | POST       |
| URL        | /products  |
| Доступ     | Admin      |

**Тело запроса:**
```json
{
  "name": "Яблоки",
  "price": 199,
  "emoji": "🍎",
  "category": "fruits",
  "weight": "1 кг",
  "stock": 50
}
```

### Обновить товар

|  Параметр  |    Значение   |
|------------|---------------|
| Метод      | PUT           |
| URL        | /products/:id |
| Доступ     | Admin         |

### Удалить товар

|  Параметр  |    Значение   |
|------------|---------------|
| Метод      | DELETE        |
| URL        | /products/:id |
| Доступ     | Admin         |


## Заказы (Orders)

### Создать заказ

|  Параметр  |    Значение   |
|------------|---------------|
| Метод      | POST          |
| URL        | /orders       |

**Тело запроса:**
```json
{
  "userId": 1,
  "items": [{"id": 1, "quantity": 2, "price": 199}],
  "total": 398
}
```

### Получить все заказы

|  Параметр  |    Значение   |
|------------|---------------|
| Метод      | GET           |
| URL        | /orders       |
| Доступ     | Admin         |

### Обновить статус заказа

|  Параметр  |         Значение        |
|------------|-------------------------|
| Метод      | PUT                     |
| URL        | /orders/:id/status      |
| Доступ     | Admin                   |

**Тело запроса:**
```json
{
  "status": "processing"
}
```


## Авторизация

### Вход в систему

|  Параметр  |    Значение   |
|------------|---------------|
| Метод      | POST          |
| URL        | /login        |

**Тело запроса:**
```json
{
  "email": "user@example.com",
  "password": "password123",
  "role": "customer"
}
```

**Пример ответа:**
```json
{
  "success": true,
  "user": {
    "email": "user@example.com",
    "role": "customer"
  }
}
```

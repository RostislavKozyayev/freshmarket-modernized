# Руководство администратора FreshMarket


## 1. Вход в систему

1. Откройте страницу входа: `http://localhost:3000/login.html`
2. Выберите роль: **Администратор**
3. Введите учётные данные:
   - Email: `admin@freshmarket.ru`
   - Пароль: `admin`
4. Нажмите кнопку **Войти**


## 2. Управление товарами

### Добавление товара

1. Перейдите в раздел **Товары**
2. Нажмите кнопку **+ Добавить товар**
3. Заполните поля:
   - Название товара
   - Цена (в рублях)
   - Эмодзи (иконка товара)
   - Категория (fruits, dairy, bakery, drinks, other)
   - Вес
   - Количество на складе
4. Подтвердите добавление

### Редактирование товара

1. Найдите товар в таблице
2. Нажмите кнопку **Редактировать**
3. Измените необходимые поля
4. Подтвердите изменения

### Удаление товара

1. Найдите товар в таблице
2. Нажмите кнопку **Удалить**
3. Подтвердите удаление в диалоговом окне


## 3. Управление заказами

### Просмотр заказов

1. Перейдите в раздел **Заказы**
2. В таблице отображаются все заказы с информацией:
   - Номер заказа
   - Клиент (email)
   - Сумма
   - Статус
   - Дата создания

### Изменение статуса заказа

1. Найдите заказ в таблице
2. В колонке **Статус** выберите новое значение:
   - Новый
   - В обработке
   - Доставлен
   - Отменён
3. Статус сохраняется автоматически

### Просмотр деталей заказа

1. Нажмите кнопку **Просмотр** в строке заказа
2. Отобразится подробная информация о заказе


## 4. Статистика

На главной странице админ-панели отображается:

| Показатель | Описание |
|------------|----------|
| Всего товаров | Общее количество товаров в каталоге |
| Заказов сегодня | Количество заказов за текущий день |
| Выручка | Общая сумма всех заказов |


## 5. Безопасность

- Доступ к админ-панели разрешён только пользователям с ролью `admin`
- При попытке прямого доступа без авторизации происходит перенаправление на главную страницу
- Данные сессии хранятся в `localStorage`


## 6. Возможные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Доступ запрещён | Пользователь не администратор | Войдите под учётной записью admin |
| Не загружаются товары | Сервер не запущен | Запустите `node server.js` |
| Ошибка сети | API недоступен | Проверьте подключение к серверу |

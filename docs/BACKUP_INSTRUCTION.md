# Инструкция по резервному копированию базы данных


## 1. Общие положения

Резервное копирование базы данных проекта FreshMarket осуществляется автоматически с помощью скрипта `backup.js`. Рекомендуется выполнять резервное копирование:
- Перед внесением изменений в структуру БД
- После массового добавления/изменения данных
- Регулярно (не реже 1 раза в неделю)


## 2. Создание резервной копии

### 2.1. Автоматическое копирование

```bash
node backup.js
```

#### Результат:
- Файл копии создаётся в папке backups/
- Имя файла содержит дату и время создания
- Пример: freshmarket_2026-03-23T14-30-00.db

### 2.2. Ручное копирование
Скопируйте файл freshmarket.db в безопасное расположение:

```bash
cp freshmarket.db ./backups/freshmarket_manual_2026-03-23.db
```


## 3. Восстановление из резервной копии

### 3.1. Автоматическое восстановление

```bash
node restore.js
```

#### Процесс:
1. Скрипт покажет список доступных копий
2. Выберите номер копии для восстановления
3. Текущая БД будет автоматически сохранена перед восстановлением

### 3.2. Ручное восстановление

```bash
cp ./backups/freshmarket_2026-03-23T14-30-00.db freshmarket.db
```


## 4. Проверка целостности данных
После восстановления выполните проверку:

```bash
node server.js
```

Откройте в браузере http://localhost:3000/api/products и убедитесь, что данные отображаются корректно.
